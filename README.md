# 4-bit Parity Protected Data Transmitter

## Overview
This project implements a 4-bit even parity generator and parity checker using Verilog HDL.

## Features
- XOR-based even parity generation
- Behavioural parity checker
- Single-bit error detection
- Testbench verification
- ModelSim waveform simulation

## Files
- parity_generator.v
- parity_checker.v
- top_module.v
- parity_tb.v

## Tools Used
- Verilog HDL
- ModelSim
